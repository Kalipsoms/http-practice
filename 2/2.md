# Статический сервер

## 1. Выполнение задания

Для реализации использовалась стандартная библиотека Python http.server.
Был создан файл server.py, который запускает сервер на локальном адресе 127.0.0.1 с портом 8765

Для обработки GET-запросов используется SimpleHTTPRequestHandler, который автоматически проверяет существование файлов и определяет их MIME-тип.

## 2. Тестирования сервера

Для проверки HTTP-статусов был создан файл test.py, использующий стандартный модуль http.client.
Были выполнены четыре запроса:
```
Проверка: GET /index.html
Статус: 200 OK
Content-Type: text/html

Проверка: GET /abc.html
Статус: 404 File not found
Content-Type: text/html;charset=utf-8

Проверка: POST /
Статус: 405 Method Not Allowed
Content-Type: None

Проверка: HEAD /style.css
Статус: 200 OK
Content-Type: text/css
```
