
# Формирование HTTP-запроса вручную через Netcat

## 1. Выполнение задания

Так как на моём компьютере не установлен Netcat, для выполнения задания я воспользовался сторонним онлайн-сервисом, предоставляющим доступ к терминалу.

В терминале была введена команда:

```bash
nc google.com 80
```

После подключения к серверу был сформирован и отправлен HTTP-запрос:

```http
GET / HTTP/1.1
Host: google.com
Connection: close

```

## 2. Полученный ответ

В результате был получен следующий ответ сервера:

```http
HTTP/1.1 200 OK
Server: nginx/1.21.6
Content-Type: text/plain
Content-Length: 42
```
