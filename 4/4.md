# Задание 4. Схема вызовов CRUD для `/users`

## 1. Цель работы

Показать основные CRUD-запросы для ресурса `/users` и указать ожидаемые HTTP-статусы ответов сервера.

## 2. CRUD-операции

CRUD — это набор базовых операций для работы с данными:

- **Create** — создание нового ресурса
- **Read** — получение ресурса
- **Update** — обновление ресурса
- **Delete** — удаление ресурса

## 3. Схема запросов для `/users`

| Операция | HTTP-метод | URL | Назначение | Ожидаемый статус |
|---|---|---|---|---|
| Create | POST | `/users` | Создание нового пользователя | `201 Created` |
| Read | GET | `/users` | Получение списка пользователей | `200 OK` |
| Read by id | GET | `/users/1` | Получение пользователя по ID | `200 OK` |
| Update | PUT | `/users/1` | Полное обновление пользователя | `200 OK` |
| Delete | DELETE | `/users/1` | Удаление пользователя | `204 No Content` |

## 4. Примеры запросов

### Создание пользователя

```http
POST /users HTTP/1.1
Content-Type: application/json
```

Ожидаемый статус:

```text
201 Created
```

### Получение списка пользователей

```http
GET /users HTTP/1.1
```

Ожидаемый статус:

```text
200 OK
```

### Получение пользователя по ID

```http
GET /users/1 HTTP/1.1
```

Ожидаемый статус:

```text
200 OK
```

### Обновление пользователя

```http
PUT /users/1 HTTP/1.1
Content-Type: application/json
```

Ожидаемый статус:

```text
200 OK
```

### Удаление пользователя

```http
DELETE /users/1 HTTP/1.1
```

Ожидаемый статус:

```text
204 No Content
```

## 5. Схема взаимодействия

```text
Клиент
  |
  |--- POST /users ---------> Сервер ----> 201 Created
  |
  |--- GET /users ----------> Сервер ----> 200 OK
  |
  |--- GET /users/1 --------> Сервер ----> 200 OK
  |
  |--- PUT /users/1 --------> Сервер ----> 200 OK
  |
  |--- DELETE /users/1 -----> Сервер ----> 204 No Content
```

## 6. Вывод

В ходе выполнения задания были рассмотрены основные CRUD-операции для ресурса `/users`.

Для создания ресурса используется запрос `POST`, для получения — `GET`, для обновления — `PUT`, для удаления — `DELETE`.

Ожидаемые статусы ответов сервера:
- `201 Created` — ресурс успешно создан
- `200 OK` — запрос успешно выполнен
- `204 No Content` — ресурс успешно удалён, тело ответа отсутствует
